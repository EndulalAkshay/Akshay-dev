# Project Setup

## How to Edit This Project

You can edit this application using your preferred IDE, GitHub, or GitHub Codespaces.

### Using Your Local IDE

Make sure Node.js and npm are installed on your system.

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

The development server will provide a local URL where you can preview your application.

### Editing Directly on GitHub

1. Open your project repository on GitHub.
2. Navigate to the file you want to modify.
3. Click the pencil icon to edit the file.
4. Make your changes.
5. Commit your changes to the repository.

### Using GitHub Codespaces

1. Open your GitHub repository.
2. Click the **Code** button.
3. Select the **Codespaces** tab.
4. Create a new codespace.
5. Edit your project files in the browser-based development environment.
6. Commit and push your changes when finished.

## Technologies Used

This project is built using the following technologies:

- **Vite** – Development server and build tool
- **TypeScript** – Type-safe JavaScript
- **React** – User interface development
- **shadcn/ui** – UI components
- **Tailwind CSS** – Styling and responsive design

## Building for Production

To create an optimized production build, run:

```sh
npm run build
```

To preview the production build locally, run:

```sh
npm run preview
```

## Deployment

You can deploy this project using any hosting platform that supports modern frontend applications, such as:

- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages

Connect your GitHub repository to your preferred hosting provider and configure the build settings.

**Build command:** `npm run build`

**Output directory:** `dist`

Make sure any required environment variables and deployment settings are configured before publishing your application.
